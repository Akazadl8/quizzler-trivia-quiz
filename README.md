# ❓ Quizzler - True or False Trivia

A desktop quiz game with a Tkinter interface. It downloads 10 random true/false questions from the Open Trivia Database, and the card flashes green or red to show if you got each one right. If you're offline it uses a built-in set of questions.

## Features

- Fresh questions from the Open Trivia DB API each game
- Green / red feedback after every answer
- Live score and final result
- Works offline with backup questions

## Built with

Python, Tkinter, requests, Open Trivia DB API

## How to run

Requires Python 3.10+.

```bash
pip install -r requirements.txt
python main.py
```
